# Outreach Tool

Python media pipeline and source footage for outreach videos. See [SETUP.md](SETUP.md) for the existing setup instructions.

[![Repository security](https://github.com/nuttallp/outreach-tool/actions/workflows/repository-security.yml/badge.svg)](https://github.com/nuttallp/outreach-tool/actions/workflows/repository-security.yml)

## Maintenance and diagnostics

[Actions](https://github.com/nuttallp/outreach-tool/actions) shows repository checks; the [Security tab](https://github.com/nuttallp/outreach-tool/security) shows available alerts. A workflow badge reports checks, not application uptime. Include the commit, error code, and sanitized reproduction when reporting a failure.

See [CONTRIBUTING.md](CONTRIBUTING.md) for changes and [SECURITY.md](SECURITY.md) for private vulnerability reports.
